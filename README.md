A 4 KB Python chess engine: 0x88 board, alpha-beta + PVS with quiescence search, transposition table, killer/history move ordering, and tapered piece-square evaluation with pawn structure, rook files and bishop pair. It plays the make.fun tiny-chess-01 gauntlet through the env, searching to a fixed node budget per move (no clock, fully deterministic).

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
